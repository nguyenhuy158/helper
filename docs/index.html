    Helper CLI

    This page provides documentation for our command line tools.

    helper

    Usage:

    helper [OPTIONS] COMMAND [ARGS]...

    Options:

    Name Type Description Default
    -V, --version boolean Show the version and exit. False
    --help, -h boolean Show this message and exit. False

    Subcommands

    • all: Show all info
    • arch: Display system architecture information.
    • disk: Disk management commands.
    • docker: Docker container and image management.
    • env: Manage environment variables.
    • file: File management and processing commands.
    • internal-ip: Display the local/internal IP address.
    • journalctl: Display useful journalctl options and examples for Linux systemd logs.
    • kill: Kill processes by name or port.
    • nixos: NixOS related commands.
    • public-ip: Display the public (external) IP address.
    • rsync: Synchronize files using rsync with common options.
    • run: Run predefined command snippets.
    • speed: Test internet speed using speedtest.net
    • system-info: Display system information including CPU, RAM, and disk usage
    • venv: Manage Python virtual environments.

    helper docker

    Docker container and image management.

    Manage Docker containers and images with subcommands for common operations.

    Subcommands: ps List containers run Run a command in a new container rm Remove one or more containers rmi Remove one or more images url Show containers with their HTTP/HTTPS URLs clean Clean up disk space by removing unused resources disk-used Show Docker disk usage information

    Examples: h d ps # List running containers h d run nginx # Run an nginx container h d rm container # Remove a container h d clean # Clean up unused Docker resources h d disk-used # Show disk usage

    Usage:

    helper docker [OPTIONS] COMMAND [ARGS]...

    Options:

    Name Type Description Default
    -v, --verbose integer range (0 and above) Increase verbosity (can be used multiple times) 0
    --help, -h boolean Show this message and exit. False

    Subcommands

    • -parse-port-string: Parse port string and return port number and protocol.
    • clean: Clean up Docker disk space by removing dangling images and unused resources.
    • disk-used: Show Docker disk usage information.
    • ps: List containers.
    • rm: Remove one or more containers.
    • rmi: Remove one or more images.
    • run: Run a command in a new container.

    helper docker -parse-port-string

    Parse port string and return port number and protocol.

    Usage:

    Options:

    Name Type Description Default
    --show-all, -a boolean Show all containers (default shows just running) False
    --http-only, -h boolean Show only containers with HTTP/HTTPS ports False
    --help boolean Show this message and exit. False

    helper kill

    Kill processes by name or port.

    TARGET can be a process name (e.g., 'python') or a port number (e.g., 8000). For names, kills all matching processes. For ports, kills the process listening on that port.

    Examples: $ helper kill python $ helper kill 8000

    Usage:

    helper kill [OPTIONS] [TARGET]

    Options:

    Name Type Description Default
    --help, -h boolean Show this message and exit. False

    helper rsync

    Synchronize files using rsync with common options.

    helper run

    Run predefined command snippets.

    Usage:

    helper run [OPTIONS] COMMAND [ARGS]...

    Options:

    Name Type Description Default
    --help, -h boolean Show this message and exit. False

    Subcommands

    • add: Add or update a snippet.
    • edit: Edit snippets file directly in your default editor.
    • exec: Execute a snippet with the given arguments.
    • list: List all available snippets.
    • remove: Remove a snippet by name.
    • show: Show the command template for a specific snippet by name or index.

    helper run add

    Add or update a snippet.

    Example: h run add click-odoo "docker exec {ODOO_CONTAINER} bash -c "click-odoo {file}""

    Note: {container} will be automatically converted to {ODOO_CONTAINER} and {db_container} to {ODOO_DB_CONTAINER}

    Usage:

    helper run add [OPTIONS] NAME [COMMAND]...

    Options:

    Name Type Description Default
    --help, -h boolean Show this message and exit. False

    helper run edit

    Edit snippets file directly in your default editor.

    Usage:

    helper run edit [OPTIONS] [EDITOR]

    Options:

    Name Type Description Default
    --help, -h boolean Show this message and exit. False

    helper run exec
