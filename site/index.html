Helper CLI

This page provides documentation for our command line tools.

cli

Usage:

cli [OPTIONS] COMMAND [ARGS]...

Options:

Name Type Description Default
-V, --version boolean Show the version and exit. False
--help, -h boolean Show this message and exit. False

Subcommands

  • all: Show all info
  • arch: Display system architecture information.
  • docker: Docker container and image management.
  • env: Manage environment variables.
  • file: File management and processing commands.
  • internal-ip: Display the local/internal IP address.
  • nixos: NixOS related commands.
  • public-ip: Display the public (external) IP address.
  • run: Run predefined command snippets.
  • speed: Test internet speed using speedtest.net
  • system-info: Display system information including CPU, RAM, and disk usage
  • venv: Manage Python virtual environments.

cli arch

Display system architecture information.

Shows the machine hardware name, which is useful for determining if you're running on x86_64, arm64, or other architectures.

Equivalent to running 'uname -m' in the terminal.

Example: $ h arch arm64

cli docker

Docker container and image management.

Manage Docker containers and images with subcommands for common operations.

Subcommands: ps List containers run Run a command in a new container rm Remove one or more containers rmi Remove one or more images url Show containers with their HTTP/HTTPS URLs

Examples: h d ps # List running containers h d run nginx # Run an nginx container h d rm container # Remove a container

Usage:

cli docker [OPTIONS] COMMAND [ARGS]...

Options:

Name Type Description Default
-v, --verbose integer range (0 and above) Increase verbosity (can be used multiple times) 0
--help, -h boolean Show this message and exit. False

Subcommands

  • ps: List containers.
  • rm: Remove one or more containers.
  • rmi: Remove one or more images.
  • run: Run a command in a new container.
  • url: Show containers with their HTTP/HTTPS URLs.

cli docker ps

List containers.

Usage:

cli docker ps [OPTIONS]

Options:

Name Type Description Default
--all, -a boolean Show all containers (default shows just running) False
--all-containers boolean Show all containers (default shows just running) False
--format, -f choice (table | json) Output format table
--help, -h boolean Show this message and exit. False

cli docker rm

Remove one or more containers.

Usage:

cli docker rm [OPTIONS] [CONTAINERS]...

Options:

Name Type Description Default
--force, -f boolean Force the removal of a running container (uses SIGKILL) False
--volumes, -v boolean Remove anonymous volumes associated with the container False
--help, -h boolean Show this message and exit. False

cli docker rmi

Remove one or more images.

Usage:

cli docker rmi [OPTIONS] [IMAGE]

Options:

Name Type Description Default
--all-tags, -a boolean Remove all versions of the image with the given name False
--force, -f boolean Force removal of the image False
--no-prune boolean Do not delete untagged parents False
--help, -h boolean Show this message and exit. False

cli internal-ip

Display the local/internal IP address.

This command shows the internal (LAN) IP address of your machine. It automatically detects the correct network interface based on your OS.

Examples: $ h ip 192.168.1.100

Note: On multi-homed systems, this shows the primary network interface's IP.

Usage:

cli internal-ip [OPTIONS]

Options:

Name Type Description Default
--help, -h boolean Show this message and exit. False

cli public-ip

Display the public (external) IP address.

This command retrieves and displays your public IP address as seen from the internet. It's useful for checking your current external network identity.

Examples: $ h pubip 203.0.113.45

Note: Requires an active internet connection. Uses ifconfig.me service by default.

cli run

Run predefined command snippets.

Usage:

cli run [OPTIONS] COMMAND [ARGS]...

Options:

Name Type Description Default
--help, -h boolean Show this message and exit. False

Subcommands

  • add: Add or update a snippet.
  • edit: Edit snippets file directly in your default editor.
  • exec: Execute a snippet with the given arguments.
  • list: List all available snippets.
  • remove: Remove a snippet by name.
  • show: Show the command template for a specific snippet by name or index.

cli run add

Add or update a snippet.

Example: h run add click-odoo "docker exec {ODOO_CONTAINER} bash -c "click-odoo {file}""

Note: {container} will be automatically converted to {ODOO_CONTAINER} and {db_container} to {ODOO_DB_CONTAINER}

Usage:

cli run add [OPTIONS] NAME [COMMAND]...

Options:

Name Type Description Default
--help, -h boolean Show this message and exit. False

cli run edit

Edit snippets file directly in your default editor.

Usage:

cli run edit [OPTIONS] [EDITOR]

Options:

Name Type Description Default
--help, -h boolean Show this message and exit. False

cli run exec

Execute a snippet with the given arguments.

Examples: h run exec click-odoo /path/to/script.py h run exec 1 /path/to/script.py h run exec --force 1 /path/to/script.py

Usage:

cli run exec [OPTIONS] SNIPPET [ARGS]...

Options:

Name Type Description Default
-f, --force boolean Skip confirmation prompt False
--help, -h boolean Show this message and exit. False
